# Omniglot downloads

This repository contains compiled macOS app releases and the signed Sparkle update feed. The application source is maintained separately in a private repository.

Download the latest Omniglot app from [Releases](https://github.com/Quan018/Omniglot-Updates/releases/latest). Existing installations with automatic updates support can use **Check for Updates…** or update in the background.

Applicable licenses and required notices are included inside the app bundle.
